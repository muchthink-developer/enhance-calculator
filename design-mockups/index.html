강화 투자 계산기 — UX/UI 리디자인 3안

공통 전제: 좌측 사이드바(입력) + 우측 캔버스(결과) 분할, corner-radius 22.375%(squircle), 진행 가이드 미터, 옵션은 "현재 → 목표" 한 줄 표기, 명시적 "계산하기" 버튼. 3안은 상세 분석 진입 방식과 정보 밀도 축에서 갈립니다.

밀도 낮음

A · Compact Console

  • 결론을 큰 헤드라인 문장으로 최상단 강조
  • 상세 분석 4종은 아코디언으로 점진적 공개(기본 1개 열림)
  • 여백이 넓고 카드 간 호흡이 김 — 처음 쓰는 사용자에게 유리
 밀도 기준(4)

B · Analyst Workspace

  • 결론을 컬러 바 형태로 간결하게 압축
  • 추천 루트 · 직작vs구매를 2단 병렬 배치
  • 상세 분석 3종은 탭으로 전환 — 한 화면에서 스위칭
 밀도 높음

C · Dense Terminal

  • 결론을 1줄 스트립으로 최소화, KPI를 즉시 노출
  • 추천 루트 · 비교표 · 기대값 요약을 3단 그리드로 동시 노출
  • 상세 확률/기대값/손익분기는 오버레이(모달)로 온디맨드 진입
squircle 관련 참고 — CSS border-radius는 원호 기반이라 진짜 superellipse(연속 곡률)는 아닙니다. 22.375%는 그 근사치로, 대부분의 카드·버튼·입력 요소에 일괄 적용했습니다. 실제 코드 반영 단계에서 더 정교한 squircle이 필요하면 SVG clip-path 기반으로 핵심 요소(윈도우 프레임, KPI 카드)만 선택적으로 교체하는 것을 권장합니다.
